# 🎓 Predicta (Projeto SIMPA)

## 📌 Sobre o Projeto
O **Predicta** é a plataforma desenvolvida pela nossa equipe para o desafio SIMPA (Sistema Inteligente de Monitoramento e Predição Acadêmica), que faz parte do Projeto Integrador do 2º período do curso de Inteligência Artificial da UniEVANGÉLICA. 

O objetivo do nosso sistema é atuar como uma ferramenta de análise sistêmica orientada a dados, capaz de coletar, organizar e interpretar dados acadêmicos (como notas e frequência). O Predicta tem um foco analítico e institucional, buscando transformar informações brutas em indicadores que ajudem na identificação de padrões e tendências, apoiando a tomada de decisão acadêmica de forma inteligente.

## 🚀 Status do Projeto e Entregas (Marco 1 - Nível 2)
Nesta primeira etapa, o foco da equipe foi a construção de uma base arquitetural sólida, modular e bem fundamentada em Programação Orientada a Objetos, preparando o sistema para o futuro módulo analítico e de interface. 

As principais entregas realizadas neste ciclo incluem:
* **Modelagem e Diagramas:** Modelagem do sistema documentada através de diagramas UML (Casos de Uso e Classes).
* **Arquitetura Orientada a Objetos:** Classes implementadas e organizadas por responsabilidade.
* **API Básica Funcional:** Implementação de rotas iniciais para tráfego e consulta de dados acadêmicos.
* **Tratamento e Organização de Dados:** Coleta, limpeza e estruturação inicial da base de dados.
* **Arquitetura Nível 2 (Separação de Camadas):** O código foi projetado com organização modular (modelo, serviço, controlador, etc.).

## 🛠️ Tecnologias Utilizadas
A base do projeto está sendo construída com as seguintes tecnologias e formatos:
* **Python**: Linguagem principal utilizada para a API (Back-end), lógica de programação e tratamento dos dados.
* **HTML e CSS**: Estruturação e estilização base preparatória para a futura interface de usuário.
* **JSON e TXT**: Formatos utilizados para o armazenamento de arquivos, estruturação da base de dados e tráfego de informações na API.
